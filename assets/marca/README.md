# Marca — arquivos originais

Os logotipos como o cliente entregou, mais o símbolo isolado em resolução cheia (de onde
saíram as versões de 256px). Esta pasta é o **acervo**: nada aqui é servido diretamente.

Quem usa cópias otimizadas:

- o painel: `imigrar-agent/public/marca/` (logotipo original e branco, símbolo em 256px);
- o site: `site/public/marca/` (logotipos em 640px).

Se um logotipo mudar, atualize aqui **e** nas cópias — e leia `imigrar-agent/IDENTIDADE.md`
antes, porque a paleta do painel e do site é amostrada pixel a pixel de
`logotipo-original.png`.
